# 快充基础概念与寄存器字段速查

> 维护: zhiqiang.yang | 日期: 2026-08-13
> 用途: 理解 IP2366 充电过程、日志字段含义、快充协议基础，便于充电/放电评估调试

---

## 一、锂电池充电三阶段（三段式）

锂电池不能一直大电流猛充，标准充电分四个阶段：

```
涓流(预充) → 恒流CC → 恒压CV → 充满停止
```

| 阶段 | 电压状态 | 电流状态 | 说明 |
|---|---|---|---|
| **涓流 Trickle** | 电池电压很低（<3.0V/节） | 小电流（~200mA） | 电池"饿过头"，先小电流慢喂，防大电流损伤 |
| **恒流 CC** | 电压持续上升 | **恒定大电流**（~3A） | 主充电阶段，充入大部分电量，最快 |
| **恒压 CV** | 电压到顶（4.2V/节）不变 | 电流**逐渐减小** | 补最后 ~20% 电量，越充电流越小 |
| **充满** | 电压满 | 电流 < 截止值（100mA） | 判定充满，停充 |

**一句话记忆**：涓流是"喂饿晕的电池"，CC 是"猛灌"，CV 是"慢慢收尾"。

## 二、IP2366 充电阶段枚举（chg 字段，0x31 寄存器 [2:0]）

`IP2366Reg.h` 定义，一共 7 个状态：

| 值 | 枚举名 | 含义 |
|---|---|---|
| `0x00` | `CHG_STANDBY` 待机 | 没在充电（空闲/等待） |
| `0x01` | `CHG_TRICKLE` 涓流 | 电池电压低，小电流预充 |
| `0x02` | `CHG_CC` 恒流 | 恒定大电流充电（主充电阶段） |
| `0x03` | `CHG_CV` 恒压 | 电压到顶，电流递减收尾 |
| `0x04` | `CHG_WAITING` 等待 | 充电过渡状态（阶段切换间隙） |
| `0x05` | `CHG_FULL` 充满 | 已充满 |
| `0x06` | `CHG_TIMEOUT` 超时 | 充电超时（异常） |

**正常充电顺序**：`0x00 → 0x01 → 0x02 → 0x03 → 0x05`

## 三、日志字段含义

以 readChargeState 日志为例：

```
state: chg=0x03 active=1 end=0 vbus=1 fault=0x00 batt=25252mV 11mA
```

| 字段 | 寄存器 | 含义 |
|---|---|---|
| `chg` | 0x31 [2:0] | 充电阶段（见上表） |
| `active` | 0x31 bit5 | 1=充电进行中 |
| `end` | 0x31 bit4 | 1=充满（CHG_End） |
| `vbus` | 0x33 bit7 | 1=Vbus 有电（充电器插着） |
| `fault` | 0x38 | 非 0 = 有故障（bit5 过流 / bit4 短路，写1清0） |
| `batt` | 0x50-51 | 电池电压 mV（16位ADC，先读低后读高） |
| 末尾数字 | 0x6E-6F | 电池电流 mA（正=充电 负=放电） |

## 四、快充协议基础

### 为什么要"协议"

普通 USB 默认只给 **5V**，功率有限（5V×3A=15W）。要更快充电就得**提高电压**（9V/12V/20V），而充电器不会随便给高压，**必须双方"协商"**——这就是快充协议。

```
默认：5V（不用协商，谁都能充）
快充：设备跟充电器"谈" → "我要 20V" → 充电器升到 20V
```

### 主流协议

| 协议 | 谁定的 | 通信方式 | 电压档位 |
|---|---|---|---|
| **USB PD** | USB-IF（行业标准） | Type-C 的 CC 线 | 5/9/15/20V，最高 100W |
| **QC（高通）** | 高通 | D+/D- 线 | 5/9/12/20V |
| **SCP / VOOC** | 华为 / OPPO | 私有 | 各家不同 |

### 关键名词

- **PDO（Power Data Object）**：PD 协议里的"电源档位"描述（如"20V 3A"是一个 PDO）。代码 `PDO select: 5` = 选第 5 档 = 20V。
- **Source / Sink**：充电器是 **Source（供电端）**，设备（IP2366）是 **Sink（受电端）**。Sink 向 Source 请求电压。
- **PD 协商**：插上后 IP2366 通过 CC 线跟充电器通信，说"我要 20V 档"，充电器同意后把 VBUS 升到 20V。

### VBUS 是什么

**VBUS = USB 线里那根电源线**（充电器提供的输入电源轨）。
- `vbus=1`：充电器插着，VBUS 有电
- `vbus=0`：没插充电器

区分：VBUS 是**输入**（充电器给的），`batt` 电压是**输出**（电池端）。IP2366 把 VBUS 变换成适合电池的充电电压。

## 五、常见现象解释

### 1. 满电 + 边充边用 → CC/CV 快速交替

电池满电时，系统负载一拉，电压掉下来（如 25.25V→24.7V），充电器切回 CC 补电；补满又切回 CV 停止。约 1 秒一个周期。**这是正常现象，不是 bug。**

### 2. 芯片唤醒后 ADC 初始读数异常

芯片唤醒后 ADC 需要 ~3 秒稳定，前 1-2 次读数可能是垃圾（如 1294mV / 3284mV）。**不影响状态机**（状态机判断用 BMS 电压，不用 IP2366 的 ADC）。

### 3. USB 非快充电流小、电压波动大

USB 5V 口功率有限（2.5~4.5W），充电电流只有 ~260mA，电压波动可达 500mV+。**物理限制，不是 bug。** 用 20V 快充才能看到 3A 大电流的 CC 平台。
